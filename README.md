# AIMEX Lab

**Artificial Intelligence for Mineral Exploration Laboratory**

This repository hosts the public AIMEX Lab website at `https://aimex-geoai.github.io`.

## Scope

AIMEX develops interpretable, reproducible GeoAI research for mineral exploration, including mineral geochemistry, metallogenic discrimination, spatial geoscience, remote sensing, mineral-potential methodology, and validation frameworks.

## Governance

The website distinguishes AIMEX research from the founder's personal academic portfolio and from proprietary employer/client work. Public repository links may point to research originally developed under the founder's personal GitHub account.
